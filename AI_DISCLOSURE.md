# AI assistance

This project was developed with AI assistance through OpenAI Codex. AI assisted with repository analysis, research of official documentation and upstream licensing, architecture, TypeScript and Solidity implementation, tests, documentation, and local integration checks. This includes the chain/RPC registry mirror, importer, Arkiv queries, and RPC discovery integration.

The registry's underlying chain metadata is existing public data from ethereum-lists/chains, republished under its MIT license. We do not claim to have created those chain definitions or the external SDKs. The mirror implementation, snapshot publishing, query interfaces and project integration were implemented in this repository. The team's submission should link this file and identify any additional AI tools or external work used by its members.
